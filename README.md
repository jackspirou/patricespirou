# Patrice Spirou

Personal biography site for Patrice Spirou, based on the layout of
[costasspirou.com](https://costasspirou.com/).

Serve this directory with `python3 -m http.server 8766` for local preview.
The site uses HTML, CSS, and local images. It has no build step.

## Content sources

Sources checked on October 29, 2026:

- [Archdiocese of Atlanta directory](https://archatl.com/about/chancery-directory/):
  current department and public portrait.
- [Families Forming Disciples](https://archatl.com/faith-life/evangelization/families-forming-disciples/):
  current title, program description, and public contact.
- [Loyola Press author biography](https://catechistsjourney.loyolapress.com/author/patrice/):
  teaching experience, speaking topics, writing, and family background.
- [Clarion Herald profile](https://clarionherald.org/news/archdiocese-of-no-explores-shift-toward-family-centered-church-supported-catechesis):
  school teaching, parish ministry, and family formation work.
- [Georgia Bulletin program report](https://georgiabulletin.org/news/2020/10/new-family-formation-program-supports-the-domestic-church/):
  role in family formation and support for parish leaders.
- [NCCL conference recording](https://www.ncclcatholic.org/recordings/whats-working-in-parent-family-faith-formation):
  presentation with Kathie Amidei.
